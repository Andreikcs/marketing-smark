## Uso no Editor

1. Abrir http://127.0.0.1:8765/editor  
2. Novo post → **Sul Contábil**  
3. Estúdio IA com marca `sul-contabil`  
4. Tema **escuro** como padrão do feed (claro só sob pedido)  
5. Entrega final: `tier=final` (Gemini)
